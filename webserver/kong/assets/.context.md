Assets for the Kong gateway service: config template, supervisor wrapper, DB grants, and icon. See parent `webserver/kong/.context.md` for the install flow.

## Summary

- avatar.png — service icon (referenced by manifest.yml `avatarUrl`)
- kong.conf — Kong config (postgres datastore on 127.0.0.1); `kong_password` token sed-replaced with %randomPassword% at install
- kong_supervised.sh — startCmd wrapper: kong start, signal traps to kong stop, 30s health poll exiting 1 when unhealthy so the OS restarts the service
- kong_user_privileges.sql — GRANT USAGE, CREATE ON SCHEMA public TO kong_user (applied via psql during install)
