Web server services for hosting and proxying applications. Each subdirectory is one installable service with a manifest and assets. (PHP WebServer/OpenLiteSpeed lives under runtime/, not here.)

## Summary

- kong/ — Kong Gateway 3.13 Enterprise (manifest.yml, assets/): DB-backed API gateway on 8000/8443, provisions its own PostgreSQL via `os db` commands, runs under a supervisor wrapper script

## Constraints

- Each web server MUST have a manifest file defining installation steps.
- Manifests adding apt sources MUST run `apt-get update -qq` before installs (issue #79 fix); kong bundles `apt-get -qqy update &&` inline with its install.
