Miscellaneous services that do not fit the database/runtime/webserver categories. Each subdirectory is one installable service with a manifest and assets.

## Summary

- hermes-agent/ — Hermes Agent (Nous Research AI agent): manifest.yml installs from a git release tag into /app/hermes-agent with a uv venv; gateway on port 8644
- openssh/ — OpenSSH server (manifest.yml, assets/avatar.jpg): plain `openssh-server` apt install, then writes `/etc/ssh/sshd_config.d/60-per-source-penalties.conf` with the loopback ranges, the runtime-discovered container's own address on the default-route interface and the default-route gateway when present; `/usr/sbin/sshd -D` on port 22
- supabase-vector/ — Vector 0.28.1 build configured for Supabase log pipelines (manifest.yaml, assets/avatar.png, assets/vector.txt): tails /app/logs and Kong logs, parses/routes per Supabase service, ships to Logflare endpoints
- vector/ — Vector 0.52 generic log pipeline (manifest.yaml, assets/avatar.png, assets/vector.txt): demo_logs → syslog parse → console sink; API on 127.0.0.1:8686

## Constraints

- Each service MUST have a manifest file defining installation steps.
- Manifests adding apt sources MUST run `apt-get update -qq` before package installs (issue #79 fix).
- The openssh install MUST fail loud when there is no default route or no usable global IPv4 address on the default-route interface — its `60-per-source-penalties.conf` drop-in needs the runtime-discovered container own address on that interface.
- Steps run through the OS executor get a trailing space appended (`tk` shell builds `Command + " " + Join(Args, " ")`, `src/infra/shell.go:163-168`). Never end a step with a line that must be byte-exact: a heredoc terminator on the step's last line becomes `EOF ` and is written into the file. Write files with a single `printf`/`echo` command instead.

## Guidance

- `vector.txt` assets are shipped as `.txt` and copied to `/etc/vector/vector.yaml` at install — keep that extension when editing.
- The two vector variants share config filename but serve different pipelines; do not cross-edit their `assets/vector.txt`.
- The openssh drop-in intentionally exempts loopback, the container own address and the default-route gateway when one exists from per-source penalties. Behind the Ez shared proxy every session arrives as that own address. So proxied SSH traffic is never penalized. This trade keeps customers reachable through the shared proxy.
