Installable service for Hermes Agent (Nous Research self-improving AI agent). The manifest installs it from a git release tag into `/app/hermes-agent` with an in-tree uv venv; `update.sh` pins an existing installation to a new release tag.

## Summary

- manifest.yml — v1 manifest: uv + node@22 via mise, shallow git clone at `--branch %version%`, `uv pip install -e ".[all]"`, config copied from repo examples, gateway started via `/root/.local/bin/hermes gateway run` (port 8644)
- update.sh — operator-run version-pinning script (`update.sh <version-tag>`): validates the tag exists on the remote, clears stale git locks (refuses while another git process runs), fetches/checks out the tag, reinstalls Python/npm deps into the existing venv, and flags pending `hermes config migrate`; prompts a service restart to load new code
- assets/ — avatar.png (service icon)

## Constraints

- MUST run from the checkout created by the install manifest (`/app/hermes-agent` with an in-tree `venv/`); update.sh refuses to create either.
- MUST NOT target `main`/`master` — update.sh pins only release tags.
