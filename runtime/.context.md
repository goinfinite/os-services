Language runtime services for executing applications. Each subdirectory contains a runtime with its manifest and assets.

## Summary

- bun/ — Bun JavaScript/TypeScript runtime (manifest.yml, assets/avatar.jpg)
- java/ — Java runtime environment (manifest.yaml, assets/avatar.jpg)
- node/ — Node.js JavaScript runtime (manifest.yml, assets/avatar.jpg)
- php-webserver/ — PHP runtime for web applications (manifest.yml, assets/avatar.jpg)
- python/ — Python runtime environment (manifest.yaml, assets/avatar.jpg)
- ruby/ — Ruby runtime environment (manifest.yaml, assets/avatar.png, startup file: genericStartupFile.rb)

## Constraints

- Each runtime MUST have a manifest file defining installation steps
- MUST include `assets/avatar.jpg` (or .png) for service identification
- Runtimes marked as `nature: multi` support multiple versions installed simultaneously
