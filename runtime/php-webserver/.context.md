The PHP web runtime: OpenLiteSpeed plus lsphp packages, installed by a channel-resolving shell script. Requests on 8080/8443; configs live under /app/conf/php-webserver, logs under /app/logs/php-webserver.

## Summary

- manifest.yml — v1 manifest (`latest`, `legacy`, 8.0–8.5 versions); delegates install to assets/install.sh, chowns conf/log dirs, registers two OS cron jobs (htaccess auto-reload every 2 min, daily /tmp/lshttpd/swap cleanup) that uninstall steps delete
- assets/install.sh — resolves the requested version to a `latest`/`legacy` channel; latest installs lsphp81–85 from repo.litespeed.sh, legacy adds the signed Infinite apt repo (fingerprint-pinned) for lsphp 5.6/7.4/80; copies the httpd/vhost configs, substituting `%primaryHostname%`
- assets/install_test.sh — asserts the version→channel mapping of resolvePhpVersionChannel (sources install.sh)
- assets/httpd_config.conf / legacy-httpd_config.conf — server-level OpenLiteSpeed configs (modern/legacy)
- assets/primary.conf / legacy-primary.conf — vhost templates (modern binds lsphp82, legacy binds lsphp74); copied to /app/conf/php-webserver as `template` + `primary.conf`
- assets/modules.yaml — PHP version → toggleable extension modules list; parsed by Infinite OS for the dashboard
- assets/avatar.jpg — service icon

## Constraints

- MUST NOT edit modules.yaml without checking the Infinite OS dashboard parser contract (README "Assets": the system installs only listed modules).
- Legacy apt key MUST be verified against the pinned fingerprint A2CFAC75CC057C4539EB235C4F0EF2A3C87015E4 (install.sh fails closed otherwise).

## Guidance

- Keep install.sh and install_test.sh in sync: the test sources the script's guard (`BASH_SOURCE` return) to reuse resolvePhpVersionChannel.
