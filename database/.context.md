Database services for Infinite OS. Each subdirectory is one installable service: a manifest defining install/uninstall/stop steps, plus assets. All are `nature: solo`, `type: database`, and provision a random root/admin password via the `%randomPassword%` placeholder stored in a root-only credentials file.

## Summary

- mariadb/ — MariaDB (manifest.yaml, assets/avatar.jpg): MariaDB repo setup script, strips MaxScale repo stanza, MySQL-compat symlinks, secure-initialization SQL, `/root/.my.cnf` credentials, config symlinked to `/app/conf/mariadb`
- mongodb/ — MongoDB 7.0 (manifest.yaml, assets/avatar.png, assets/mongod.conf): pinned apt repo (Debian trixie mapped to bookworm packages), conf copied from assets, binds 127.0.0.1:27017
- opensearch/ — OpenSearch 2.x (manifest.json, assets/avatar.jpg): generates a full TLS PKI for the security plugin, rewrites `/etc/opensearch/opensearch.yml`, requires `vm.max_map_count >= 262144`
- postgresql/ — PostgreSQL 12–16 (manifest.json, assets/avatar.jpg): pgdg apt repo, snakeoil-cert group fixup, scram-sha-256 after temp trust auth, `/root/.pgpass` + postgres `.pgpass` credentials
- redis/ — Redis 6.2–7.2 (manifest.yaml, assets/avatar.jpg): pinned apt repo (trixie mapped to bookworm), foreground daemonize fix, log ownership under `/app/logs/redis`

## Constraints

- Each service MUST have a manifest file defining installation steps.
- Install steps MUST run a standalone `apt-get update -qq` after adding an apt source and before package installs (issue #79 fix).
- Auto-generated credentials MUST be written to root-only files (chmod 400) — e.g. `/root/.my.cnf`, `/root/.pgpass`, `/root/.opensearchpass`.
- Service config MUST be exposed to the OS via a `/app/conf/<name>` symlink to the real config dir, removed on uninstall.
