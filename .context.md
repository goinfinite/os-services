Service manifests for Infinite OS. Each subdirectory contains installable services with their manifests (JSON/YAML) and assets.

## Summary

- database/ — Database services (MariaDB, MongoDB, OpenSearch, PostgreSQL, Redis)
- other/ — Miscellaneous services (OpenSSH, Supabase Vector, Vector)
- runtime/ — Language runtimes (Bun, Java, Node, PHP, Python)
- system/ — Core system services (Cron, Nginx, OS API)
- webserver/ — Web server services (Kong, PHP WebServer)
- README.md — Project overview and manifest schema documentation
- CHANGELOG.md — Version history and changes
- LICENSE.md — Project license
- CONTRIBUTING.md — Contribution guidelines

## Constraints

- MUST NOT modify `.agents/` directory — managed externally
- Each service MUST have a manifest file (`.json`, `.yml`, or `.yaml`)
- Service directories MUST contain an `assets/` subdirectory
