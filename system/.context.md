Core system services required for Infinite OS operation. These services are managed by the OS itself and cannot be created, updated, or removed by users.

## Summary

- cron/ — Cron job scheduler (assets/avatar.jpg)
- nginx/ — Nginx web server/reverse proxy (assets/avatar.jpg)
- os-api/ — Infinite OS API service (assets/avatar.jpg)

## Constraints

- These services are `type: system` and managed internally by Infinite OS
- No manifest files — configuration is handled by the OS directly
- Users cannot create, update, or remove these services
